# {mine, craft}*
Procedurally-generated voxel-based infinitely-scrolling Minecraft landscape for the browser.

Inspired by [{Shan, Shui}*](https://github.com/LingDong-/shan-shui-inf) and uses noises and mathematical functions modified from Minecraft's world-generation to model terrain as viewed from a lateral observer.
